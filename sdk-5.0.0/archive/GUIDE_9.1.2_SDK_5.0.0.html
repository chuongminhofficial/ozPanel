1. Bắt đầu nhanh cho Nhà phát triển (5 phút)

ozsdk.py trong SDK 5.0.0 hỗ trợ chạy trực tiếp trên Linux, macOS và Windows để bạn khởi tạo, kiểm thử và đóng gói Addon ngay trên máy lập trình.

python3 ozsdk.py --version
python3 ozsdk.py init ./my-addon --id 9010 --publisher my-studio --name "My Super Addon" --category automation
python3 ozsdk.py validate ./my-addon
python3 ozsdk.py audit ./my-addon
python3 ozsdk.py keygen --out ./keys
python3 ozsdk.py pack ./my-addon --out ./dist/addon_9010.ozaddon --sign-key ./keys/publisher-private.pem
python3 ozsdk.py verify ./dist/addon_9010.ozaddon --pub-key ./keys/publisher-public.pem

2. Cấu trúc gói .ozaddon & Đặc tả manifest.json

{

}

install.sh, upgrade.sh, health.sh, rollback.sh, uninstall.sh — đều phải idempotent và không hỏi read tương tác trong install.sh.

4. Ký số Ed25519, SBOM & Phân phối qua GitHub Raw

Khuyên dùng: Phân phối gói .ozaddon qua https://raw.githubusercontent.com/<user>/<repo>/main/addon_9010.ozaddon để tránh lỗi redirect khi máy chủ tải trực tiếp.
python3 ozsdk.py sbom ./my-addon --out ./dist/addon_9010.sbom.json
python3 ozsdk.py catalog ./dist/addon_9010.ozaddon --url "https://raw.githubusercontent.com/user/repo/main/addon_9010.ozaddon"
python3 -m unittest discover -s tests -p "test_*.py" -v

1. Cách cài đặt Addon trên OZPanel v9.1.2

Qua SSH Terminal [15]

Gõ oz → chọn 15 (Kho tiện ích) → chọn 1 để cài từ Chợ hoặc 6 để dán URL .ozaddon trực tiếp.

Qua Web GUI [27]

Đăng nhập Web GUI (cổng 8443) → mở thẻ [15] Kho tiện ích → bấm nút cài đặt / chạy trực quan bằng chuột.

# Cài nhanh OZPanel v9.1.2 từ link Raw chính thức
curl -fsSL https://raw.githubusercontent.com/chuongminhofficial/ozPanel/main/install.sh | sudo bash
