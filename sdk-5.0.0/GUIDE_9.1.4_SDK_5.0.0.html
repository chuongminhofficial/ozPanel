Bắt đầu nhanh cho Nhà phát triển (5 phút)

Công cụ ozsdk.py hoạt động trên Linux, macOS và Windows. Bản v9.1.4 đã đồng bộ đầy đủ các cờ CLI (--category, keygen --out, pack --sign-key, verify --pub-key, trust --publisher --pub-key).

Terminal · CLI Quickstart
python3 ozsdk.py --version
python3 ozsdk.py doctor
python3 ozsdk.py init ./my-addon --id 9010 --publisher my-studio --name "My Super Addon" --category automation
python3 ozsdk.py validate ./my-addon
python3 ozsdk.py audit ./my-addon
python3 ozsdk.py keygen --out ./keys
python3 ozsdk.py pack ./my-addon --out ./dist/addon_9010.ozaddon --sign-key ./keys/publisher-private.pem
python3 ozsdk.py verify ./dist/addon_9010.ozaddon --pub-key ./keys/publisher-public.pem

5 Lifecycle Hooks Idempotent

Các hook install.sh, upgrade.sh, health.sh, rollback.sh và uninstall.sh không được dùng lệnh read tương tác để cài mượt qua Web GUI [27].

Web GUI [27] Workbench (OZ_GUI_FORM=1)

Khai báo gui_workbench.actions và đọc biến môi trường OZ_ACTION_KEY khi oz_is_gui_form kích hoạt để chạy không cần terminal.
